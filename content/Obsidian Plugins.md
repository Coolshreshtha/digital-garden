 So my most recent obsession is creating a vault for grad school with obsidian. In the process i've discovered these gems


Dataview
can be used to query vault in 4 view types, TABLE, LIST, CALENDAR, TASK. 
SImple queries can mimic a lot of functionality of logseq and notion, I see promis in terms of using dataview to list all the files related to a tag or task to list all tasks.

NVDH used a system that I've thought of before but tried to implement with a few tools and failed. She used meta bind to create a button that generates a new file using templater, and dataview query pulls it up in a table.

(sidenote, NVDH videos are crazy good at explaining obsidian things. After watching her videos on Dataview, Templater and Excalidraw, I manages to use them so well)

Templater 
A lot of dynamic templating for notes. It can have single line or file templates. Can use to generate file names and dates dynamically. Can even use a template based on which folder the file is in.

Excalidraw
for drawing. But NVDH used a back of the card analogy that i really appreciated and have now implemented in my grad school notes


Meta-bind
to create buttons, it has a ui for the meta-bind code that you can use to configure actions for buttons. I used it with quick add to create a focus session page and tried to rig a pomodoro to it. I think the pomodoro bit might just be easier as toggle open and then start manually

Pomodoro Timer
nice clean pomodoro timer with optional task list for the session and auto logs

Homepage
For creating a homepage. I really like one i created using the canvas

Latex Suite 
For faster latex snippets for math and symbols in text
