I have a thing about quota limits, and it came to the fore when overleaf gave me a build time limit on a recent project. That was enough motivation to spend and entire morning, and then some, to set up latex into my trusty local VS code.  

I used the instructions in these two tutorials but modified for windows:
* https://groundwater.usu.edu/blog/2025/Use-Latex-in-VScode/
* https://mark-wang.com/blog/2022/latex/

In a nutshell, it involved downloading [TexLive For Windows](https://www.tug.org/texlive/windows.html) and combining it with [Latex Workshop Plugin for VS code](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop), along with some adjustments for adding the right path and cleaning my VS Code user data (more of a me issue). Then I played around with some sample files and the [manual for the plugin](https://github.com/James-Yu/LaTeX-Workshop/wiki/View#internal-pdf-viewer)
